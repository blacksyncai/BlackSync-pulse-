# Pipeline search and contact-first cards

The Opportunities toolbar now searches the selected pipeline by deal name, account name, linked point-of-contact name and email. It debounces typing, supports multiword names split across first/last name, and keeps every match inside the active pipeline filter. Clearing the input or switching pipelines resets the search interaction. Escape closes results; arrow keys and Enter select them.

Selecting a result leaves the board intact, loads that record into the visible board if it is outside the initial page, scrolls to its card, focuses it and applies a persistent outline until the next selection/clear. This covers results beyond the original 1,000-card initial limit. Boards also expose Load more cards. Missing/deleted stage values appear under Unassigned stage so search results remain reachable. Search does not search other pipelines or unrelated contacts that are not linked to an opportunity.

Contact names now appear before value, at 18px/bold, in an accented panel with wrapping rather than truncation. Contact visibility still respects Customize cards. Existing edit, communication and drag controls remain. A temporarily located card follows successful stage edits/moves and disappears after deletion or a move to another pipeline. With partial board data, the displayed currency total is explicitly labeled loaded value.

Validation: six filter tests passed, including pipeline isolation, legacy/default pipeline membership, split names and wildcard escaping. An isolated Chromium fixture passed prominent-name sizing, keyboard selection, reaching an initially unloaded card, scrolling/focus/highlight, editing its stage, clearing, no-result/Escape behavior, pipeline switching and mobile overflow. API, debounce and theme boundaries were mocked in that fixture; it does not replace the production build or an authenticated workspace search check. Public UI icon exports were checked directly to avoid the prior forms icon build failure.
